# شکار مشتریان در آستانه ریزش | Customer Churn Prediction

پروژه‌ای در حوزه **Data Mining و Machine Learning** با هدف تحلیل رفتار خرید مشتریان، شناسایی الگوهای منتهی به ریزش و طراحی راهبردهای داده‌محور برای حفظ مشتری.

## درباره پروژه

در این پروژه، تراکنش‌های یک فروشگاه آنلاین تحلیل می‌شوند تا مشتریانی که احتمال دارد در آینده خرید خود را متوقف کنند، شناسایی شوند.

چالش اصلی این است که دیتاست اولیه برچسب آماده‌ای برای ریزش مشتری ندارد. بنابراین، با تعریف یک معیار زمانی برای ریزش، مهندسی ویژگی‌های رفتاری و استفاده از الگوریتم‌های یادگیری ماشین، یک فرایند تحلیلی برای پیش‌بینی ریسک ریزش طراحی می‌کنیم.

هدف پروژه فقط ساخت یک مدل پیش‌بینی نیست؛ بلکه بررسی کیفیت داده‌ها، اعتبار نتایج، عوامل مؤثر بر رفتار مشتری و کاربرد خروجی مدل در تصمیم‌گیری‌های تجاری است.

## اهداف پروژه

- بررسی کیفیت داده‌های خام و شناسایی مقادیر گمشده، رکوردهای تکراری، لغو سفارش‌ها و مرجوعی‌ها
- تعریف عملیاتی ریزش مشتری بر اساس رفتار خرید در آینده
- استخراج ویژگی‌های رفتاری و تحلیل الگوهای خرید مشتریان
- ساخت و مقایسه مدل‌های پیش‌بینی ریزش
- ارزیابی زمانی مدل‌ها و جلوگیری از نشت اطلاعات
- تحلیل عوامل مؤثر بر ریسک ریزش
- طراحی راهبرد حفظ مشتری بر اساس خروجی مدل و محدودیت بودجه
- بررسی امکان بهبود تحلیل با استفاده از خوشه‌بندی مشتریان

## دیتاست

**منبع:** [UCI Online Retail Dataset](https://archive.ics.uci.edu/dataset/352/online+retail)

این دیتاست شامل تراکنش‌های یک فروشگاه آنلاین بریتانیایی در بازه دسامبر ۲۰۱۰ تا دسامبر ۲۰۱۱ است.

ستون‌های اصلی شامل شماره فاکتور، کد و توضیحات محصول، تعداد، تاریخ تراکنش، قیمت واحد، شناسه مشتری و کشور هستند.

## روش انجام پروژه

### 1. Data Auditing & Cleaning
بررسی ساختار و کیفیت داده‌ها، تحلیل تراکنش‌های نامعتبر و مستندسازی تصمیم‌های پاک‌سازی.

### 2. Churn Label Engineering
تعریف ریزش به‌صورت نداشتن خرید معتبر در ۹۰ روز پس از تاریخ مرجع و ساخت برچسب هدف با جداسازی اطلاعات گذشته و آینده.

### 3. Feature Engineering
استخراج ویژگی‌های رفتاری مشتریان، شامل معیارهای RFM، تغییرات تعداد و مبلغ خرید، فاصله بین سفارش‌ها و تنوع محصولات.

### 4. Modeling
ساخت مدل خط مبنا و مقایسه الگوریتم‌های زیر:

- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting / XGBoost

### 5. Temporal Evaluation
طراحی ارزیابی زمانی، کنترل نشت اطلاعات و مقایسه عملکرد مدل‌ها با معیارهای مناسب.

### 6. Model Interpretation
تحلیل اهمیت ویژگی‌ها با روش‌هایی مانند Feature Importance، Permutation Importance و SHAP.

### 7. Customer Retention Strategy
رتبه‌بندی مشتریان بر اساس ریسک پیش‌بینی‌شده، انتخاب مشتریان هدف و طراحی سناریوی کمپین حفظ مشتری با تحلیل اقتصادی.

### 8. Customer Segmentation
بررسی امکان استفاده از K-Means برای شناسایی گروه‌های رفتاری و مقایسه نتایج با روش پایه.

## معیارهای ارزیابی

برای بررسی عملکرد مدل‌ها از معیارهای زیر استفاده می‌شود:

- Precision
- Recall
- F1-score
- PR-AUC
- ROC-AUC
- Confusion Matrix

با توجه به ماهیت مسئله، انتخاب مدل نهایی صرفاً بر اساس Accuracy انجام نمی‌شود.

## محدودیت‌ها

- برچسب ریزش به‌صورت تحلیلی تعریف می‌شود و نشان‌دهنده لغو قطعی عضویت مشتری نیست.
- محدودیت بازه زمانی دیتاست بر طراحی ارزیابی زمانی تأثیر می‌گذارد.
- نتایج مدل به‌تنهایی رابطه علّی میان ویژگی‌ها و ریزش را اثبات نمی‌کنند.
- اثربخشی واقعی کمپین حفظ مشتری به آزمایش کنترل‌شده و مقایسه با گروه کنترل نیاز دارد.
